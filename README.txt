Before launch:
1. Images are remote illustrative stock photos, not photos of your actual property. Replace them with your own photos for accuracy and trust.
2. Review all descriptions and confirm every facility before publishing (private pool, breakfast, Kerala meals, bonfire, parking, travel desk, etc.).
3. In script.js, replace reservations@orangeskywayanad.com with the real working reservation email. The form opens the visitor's email app and does not store bookings or check room availability.
4. Add the correct phone/WhatsApp number and social media links.
5. Confirm attraction names, distances and travel times before publishing.

Free hosting with GitHub Pages:
1. Create/sign in to https://github.com/
2. Create a public repository (e.g. orange-sky-wayanad).
3. Upload all HTML files, styles.css and script.js to the repository root.
4. Open Settings → Pages, deploy from the main branch and /(root).
5. Add orangeskywayanad.com or www.orangeskywayanad.com as the custom domain in Pages settings.
6. Follow GitHub's current instructions and add the DNS records in GoDaddy: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
7. Enable HTTPS once available.

Domain renewal is still paid through GoDaddy. GitHub Pages hosting is free for a public repository. DNS and HTTPS can take time to activate.
